# Notes API (PostgreSQL, Express, TypeScript)

A RESTful Notes API built with Node.js, Express, Typescript, and
PostgreSQL, using sequelize ORM for database persistence.

This project demonstrates core backend development concepts including database integration, CRUD operations, validation, and proper project structure.

## Features

- Create a note
- Get all notes
- Get notes by id
- Update a note
- Delete a note
- PostgreSQL database integration
- Request validation
- Environment-based configuration
- Type-safe backend using TypeScript

## Tech stack

- Node.js
- Express
- TypeScript
- PostgreSQL
- Sequelize ORM
- dotenv

## Database

Sequelize automatically creates the **notes** table with:

- id (Primary key)
- title
- content
- createdAt
- updatedAt

## Learning Objectives

This project was built to understand:

- Backend project structure
- Express routing
- PostgreSQL integration
- Sequelize ORM
- CRUD API design
- Request validation
- Environment configuration
- TypeScript in backend development
